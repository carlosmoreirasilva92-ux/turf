# TURF

Caderno de corridas em português europeu. O cartão de hoje fica ancorado a uma hora, o modelo nomeia um cavalo e cinco agentes (forma, pista, mercado, estábulo e peso) podem alinhar, discordar ou abster-se. O resultado entra depois. Não é conselho de aposta.

Cartão de demonstração, com cotações travadas. Não há feed ao vivo.

```bash
npm install
npm run dev
```
